# Design
Implement the supplied workflow as a deterministic state machine with a transactional PostgreSQL inbox/outbox. Keep ingestion metadata durable without persisting arbitrary inbound text that may include certificate passwords. PDF storage is private and content-addressed. Certificate material remains in RAM with expiry and single-use consumption. Live connector availability is shown explicitly. Court signatures/revocations require reviewed procedure and human evidence. Operator approvals compare the current state/version and approved document hash. A case completes only after verified CRM filing, verified Carmen notice and client notification.

The chosen approach uses the requested stack and a modular monolith worker service. Pure browser automation alone would lack durable recovery; an LLM agent would violate deterministic actions. Questions are saved separately per the user's instruction to proceed without waiting. Acceptance: strict TypeScript build, real PostgreSQL/Redis and HTTP health verification, real-document harness that fails when fixtures/evidence are missing, and an explicit production readiness report. No fake success for unavailable vendor integrations.
